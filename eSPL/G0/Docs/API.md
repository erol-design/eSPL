## stm32g0_adc.h

ADC1 of STM32G0B1 (RM0444 Rev 6 section 15; Docs/v0.5_ADC_CONTRACT.md). Written for G0: the G4 ADC model (SQR1..4, injected group, ADC pairs, DEEPPWD, differential inputs) does not apply. G0 model: one ADC, CFGR1/CFGR2 writable only with ADEN = 0, channel selection in CHSELR as a bit mask (fixed order, forward/backward) or as an ordered list of up to 8 channels 0..14, two sampling times (SMP1/SMP2 + SMPSEL), CCRDY handshake after every channel configuration. RCC clock (RCC_PERIPH_ADC, RCC_KERNEL_ADC), analog GPIO mode, the regulator start-up time (tADCVREG_STUP) and sensor start-up times are the caller's duty. AUTOFF / WAIT / LFTRIG: v0.11 ADC_LowPowerConfig (call it after ADC_RegularConfig, which writes AUTOFF / WAIT = 0). Not reentrant: serialise calls. No register write on error. Errata ES0548 Rev 4: 2.6.2 / 2.6.4 (CFGR1 / CFGR2 written only with ADEN = 0, never with an automatic disable/enable), 2.6.3 (AWD1 single channel in single mode, see ADC_Awd1Config), 2.6.1 / 2.6.5 / 2.6.6 caller notes below. Caller duties (all APIs): RCC bus and kernel clock (RCC_PERIPH_ADC, RCC_KERNEL_ADC); analog GPIO mode on the input pins; the tADCVREG_STUP and sensor start-up waits; bounded polls of the *Ready / *Done / *Stopped / *Disabled queries (no API waits); the trigger source (timer TRGO, EXTI) and the DMA channel when used; serialise calls (not reentrant, ISR included). Usage: ADC_PowerRegulator, wait tADCVREG_STUP, ADC_StartCalibration / ADC_CalibrationDone, configuration with ADEN = 0 (ADC_CommonClockConfig, ADC_RegularConfig, ADC_ChannelConfig, ADC_SamplingConfig), ADC_Enable / ADC_Ready, then ADC_Start and ADC_TryRead (or DMA).

## stm32g0_aes.h

AES hardware accelerator driver (RM0444 Rev 6 section 20). New for G0 (the G4 SPL has no AES). Scope: single instance. v0.9 SKU profile: this API exists only where the device has the peripheral (SPL_G0_HAS_AES): STM32G041 / G061 / G081 / G0C1. Chaining: ECB, CBC, CTR, GCM (GMAC = GCM without payload phase), CCM; key 128 or 256 bit. Usage: AES_Config, AES_SetKey, AES_SetIv, (GCM / CCM: AES_SetPhase), AES_Enable, then per block AES_WriteBlock and AES_TryReadBlock / AES_TryComplete; AES_Disable at the end. Common rules: no static state, no waits: every wait is the caller's poll of AES_TryReadBlock / AES_TryComplete / AES_GetEnabled. Caller duties (all APIs; not done by the driver):  - AHB clock: RCC_EnablePeriphClock(RCC_PERIPH_AES).  - Message formatting: GCM ICB / CCM B0 in the IV registers (RM0444 Tables 109 / 110), CCM B1,    zero padding of the last block, GCM / CCM length block in the final phase, ciphertext    stealing for ECB / CBC (RM0444 20.4.6), tag masking and tag comparison.  - Sequence: the procedures of RM0444 20.4.4 .. 20.4.12; the phase rules below are checked only    where the register state shows the violation.  - DMA channels and DMAMUX requests (AES_IN 6, AES_OUT 7, RM0444 Table 55).  - Interrupts (AES_InterruptConfig): NVIC enable and handler of the AES vector.  - Concurrency: serialize callers (ISR included); AES_TryReadBlock and AES_TryComplete must    not run concurrently. Word order (no guessing): key[i] is written to AES_KEYRi (key[0] = KEY[31:0], RM0444 Table 111); iv[i] to AES_IVRi (iv[0] = IVI[31:0]); data blocks are four words in AES_DINR / AES_DOUTR order, block[0] = bits [127:96] first (RM0444 20.4.13). v0.11: suspend / resume (AES_Suspend / AES_Resume, below). Errata: none of ES0488 Rev 7, ES0546 Rev 4, ES0412 Rev 6, ES0549 Rev 4 lists an AES item. Contract: Docs/v0.9_AES_CONTRACT.md.

Declared only when `SPL_G0_HAS_AES` is 1 (stm32g0_sku.h); on other SKUs a call does not compile.

### `AES_Config`

```c

```

EN = 1 -> STATE (RM0444 20.7.1: MODE / CHMOD / DATATYPE / KEYSIZE writes are ignored while EN = 1). PARAM: chaining > CCM, mode > 3, key_256 > 1, data_type > 3; Mode 4 with other than ECB / CBC (hardware would silently use Mode 3, RM0444 20.7.1); Mode 2 or 4 with GCM / CCM (forbidden, RM0444 Table 109 note); Mode 2 or 4 while DMAINEN / DMAOUTEN is set (no effect / not recommended, 20.7.1: call AES_DmaConfig(0, 0) first). Writes CR: the fields above, GCMPH = init, NPBLB = 0, EN = 0; CCFIE / ERRIE and DMA enables kept.

- Caller: ECB / CBC decryption in Mode 3 needs a Mode 2 key derivation first (or use Mode 4) (RM0444 20.4.6).
- Level: `PARAM[F] STATE[F]`

### `AES_WriteBlock`

### `AES_TryReadBlock`


## stm32g0_rng.h

True random number generator driver (RNG, RM0444 Rev 6 section 19). Scope: single instance; G0: only on STM32G041 / G061 / G081 / G0C1 (SPL_G0_HAS_RNG); elsewhere this API is not declared. Usage: optional RNG_ClockErrorDetectionConfig (RNGEN=0), RNG_Enable, then poll RNG_TryRead; on ERR_HW read RNG_GetErrors and recover with RNG_SeedErrorRecover / RNG_ClearClockError. Common rules: no static state, no waits (RNG_SeedErrorRecover reads a fixed 12 words). Caller duties (all APIs; RCC module / board layer, not done here):  - RNG kernel clock: RCC_SetKernelClock(RCC_KERNEL_RNG, HSI16 / SYSCLK / PLLQ) and    RCC_SetRngDivider (RM0444 5.4.21; RNGSEL reset value 00 = no clock). Validation    conditions: 48 MHz with CED = 0 (RM0444 19.6.2). With clock error detection on, the    RNG clock must be above HCLK/32 or CECS is always set (RM0444 19.3.6).  - AHB clock: RCC_EnablePeriphClock(RCC_PERIPH_RNG) (RCC_AHBENR.RNGEN).  - Voltage range 1 for certified entropy: ES0488 2.6.1 / ES0546 2.8.1 / ES0412 2.8.1 /    ES0549 2.8.1 "RNG entropy not guaranteed with Range 2" (documentation item; the driver    does not read PWR).  - Interrupts (RNG_InterruptConfig): NVIC enable and handler of the RNG vector.  - Concurrency: serialize callers (ISR included); RNG_TryRead and RNG_SeedErrorRecover must    not run concurrently. Contract: Docs/v0.11_RNG_CONTRACT.md.

Declared only when `SPL_G0_HAS_RNG` is 1 (stm32g0_sku.h); on other SKUs a call does not compile.

SPI driver for STM32G0 (RM0444 Rev 6 section 35), with the I2S mode of SPI1 / SPI2 (v0.10). Scope: SPI1, SPI2, SPI3 on G0B1 (SPI3 guarded for G0 SKUs without it); legacy API (v0.8 .. v0.10), extended configuration (v0.11) and I2S (last section). Usage: SPI_Init (or the legacy SPI_MasterInit) with SPE = 0, optional SPI_ITConfig / SPI_DmaConfig / SPI_DmaPackingConfig, SPI_Enable(spi, 1), then the Try* transfers; SPI_Enable(spi, 0) to stop. Common rules: no dynamic memory, no static state; no function waits (BUSY / WOULD_BLOCK are returned instead); not reentrant per instance (see the serialization duty below); output parameters are unchanged unless SPL_OK (METHOD 1.8). Any read of SPIx_SR clears FRE by hardware (RM0444 35.9.3); every service that checks a flag reads SR. In TI slave mode capture FRE with SPI_GetErrors before calling other services. Caller duties (all APIs; not done by the driver):  - Clock: RCC bus clock and reset of the instance; prescaler values divide PCLK (I2S: kernel    clock RCC_KERNEL_I2S1 / RCC_KERNEL_I2S2 selected before I2S_Init).  - Pins: SCK / MISO / MOSI / NSS (I2S: CK / WS / SD / MCK) in their GPIO alternate function;    with software NSS the chip select is a GPIO driven by the caller.  - Interrupts / DMA: NVIC line, priority and handler; DMA channel / DMAMUX setup.  - Serialize all calls per instance (ISR included); CR1 / CR2 are read-modify-written. Contract: Docs/v0.3_SPI_CONTRACT.md (SPI; I2S mode is out of its scope); I2S: Docs/v0.10_COMM_MODES.md.

### `SPI_Enable`

```c
SPL_Status SPI_Enable(SPI_TypeDef *spi, uint8_t enable);
```

Disabling returns SPL_BUSY while BSY=1 (slave: only with TX FIFO not empty, see ERRATA below), or while TX FIFO is not empty in master mode. v0.11.1: slave with TX FIFO not empty and BSY=0 -> ERR_STATE (the master may have stopped clocking; only RCC_AssertPeriphReset/RCC_ReleasePeriphReset empties it). Caller may drain RX FIFO using SPI_TryRead8 while SPE=0. OVR reports SPL_ERR_HW and requires a separate recovery procedure. v0.11: enabling with MODF set returns SPL_ERR_HW without a write (hardware refuses SPE=1 while MODF=1, RM0444 35.5.11). ERRATA ES0548 2.14.2: slave (MSTR=0) with TX FIFO empty disables even while BSY=1 (BSY may stick high). The caller detects the end of the slave transaction first (NSS high, or the expected RXNE count) and calls SPI_Enable(0) only then. Slave BUSY (BSY=1, FTLVL!=0): bound the retries, then RCC reset. Master: BSY=1 or FTLVL!=0 -> BUSY (unchanged). ERRATA ES0548 2.14.1: master disables only with FTLVL=0 (TXE=1) and BSY=0; master RX-only is refused by SPI_Init; slave: do not remove NSS during a frame.

- Caller: enable = 0: wait for the end of the transfer (slave: NSS high or the expected RXNE count, ES0548 2.14.2); bound BUSY retries; after slave ERR_STATE use RCC reset and init again; drain the RX FIFO before the next enable. With DMA follow the SPI_DmaConfig order.
- Level: `PARAM[F] STATE[r] HW[r] BUSY[r]`

## stm32g0_tim.h

TIM driver (RM0444 Rev 6 sections 21..25, Docs/v0.4_TIM_CONTRACT.md), ported from the STM32G4 SPL v0.13.4. G0B1 instances: TIM1 (advanced), TIM2 (32 bit), TIM3, TIM4, TIM6, TIM7 (basic), TIM14 (one channel; no master/slave, repetition, break or DMA), TIM15, TIM16, TIM17. ERRATA ES0487 2.6.6 (TIM16 / TIM17 clocked by SYSCLK, not TIMPCLK; G030 / G031 / G041 / G050 / G051 / G061 / G070 / G071 / G081, ES0486 2.6.5, ES0488 2.7.6, ES0544 2.7.5, ES0545 2.8.5, ES0546 2.9.5, ES0468 2.6.5, ES0418 2.8.6, ES0412 2.9.6): their prescaler and periods follow SYSCLK and ignore the AHB / APB prescalers; they work only while SYSCLK / PCLK <= 4. Caller: compute TIM16 / TIM17 timing from SYSCLK and keep HPRE x PPRE <= 4 when they run (RCC_SetAhbPrescaler / RCC_SetApbPrescaler). Peripheral clocks, GPIO AF mapping and IRQ priority are board responsibilities. This module is non-blocking, keeps no static state and does not install interrupt handlers. On SPL_ERR_PARAM no register is written. Usage: configure with CEN = 0 (channels with CCxE = 0): TIM_BaseInit, optional TIM_CounterInit and channel init, TIM_GenerateUpdate, then TIM_Enable. Caller duties (all APIs): TIMx bus clock on (RCC); TIM1 / TIM15 kernel clock source if selected (TIM1SEL / TIM15SEL); PSC / ARR / CCR / DTG computed from the actual timer clock; GPIO AF for the CHx, CHxN, ETR and BKIN pins; IRQ handler, NVIC priority and enable (the handler clears the flags it serves with TIM_ClearFlags / TIM_ClearUpdate); serialise calls per instance with ISRs using the same timer (CR1, CR2, DIER, CCER, CCMRx, SMCR are read-modify-write).

### `TIM_MainOutputEnable`

```c
SPL_Status TIM_MainOutputEnable(TIM_TypeDef *tim, uint8_t enable);
```

BDTR.MOE set/clear. TIM1/15/16/17 only, else PARAM. enable=1 returns BUSY (no write) while BKDSRM or BK2DSRM is still set (break re-arm in progress, RM0444 21.3.16); retry. The write never copies BKDSRM/BK2DSRM back as 1. CALLER ORDER (LOCK write-once, RM0444 21.4.20): this function writes BDTR, and the first BDTR write after reset freezes LOCK. Called before TIM_BreakDeadTimeInit it freezes LOCK at 0; the later TIM_BreakDeadTimeInit then returns SPL_ERR_STATE (LOCK read-back). Order: TIM_BreakDeadTimeInit, then TIM_MainOutputEnable. Only a reset clears LOCK. Idle level: CR2.OISx / OISxN are never written by the driver (reset value 0). With MOE = 0 (RM0444 Table 120): OSSI = 0 -> outputs not driven by the timer (Hi-Z; the pin level is set by the GPIO configuration, e.g. a pull resistor); OSSI = 1 -> outputs enabled at the inactive level (OCx = CCxP, OCxN = CCxNP), then after a break and a dead time OCx = OISx = 0, OCxN = OISxN = 0. v0.15 (CCL-2 ZMN-23), enable=1: a set break flag of this timer (BIF; B2IF/SBIF where the timer has them) -> SPL_ERR_HW, no write; after the write MOE is read back and a MOE the hardware did not latch (break input still active) -> SPL_ERR_HW (state on failure: BDTR written with the MOE request, MOE = 0 in hardware, no other field changed). Caller: remove the break cause, clear the flag with TIM_ClearFlags (it stays set while the input is active), retry. The flags are never cleared here. enable=0 always clears MOE (flags not checked). AOE (TIM_BreakDeadTimeInit auto_output_enable = 1): hardware sets MOE again at the next update event after the break input is released, without this function; choose it only when an automatic restart is intended.

- Caller: call TIM_BreakDeadTimeInit first (LOCK write-once, only a reset clears it); after SPL_ERR_HW remove the break cause, clear the flag with TIM_ClearFlags, retry.
- Level: `PARAM[F] HW[r] BUSY[r]`

## stm32g0_wwdg.h

System window watchdog (RM0444 Rev 6 section 29). Usage: WWDG_Config, then WWDG_Enable, then WWDG_Refresh inside the window. Single WWDG instance, no static state, no function waits. Output parameters are written only on OK. Activation (WDGA) is irreversible until reset; EWI cannot be cleared by software. Caller duties (all APIs): WWDG APB clock enabled (RCC) before the first call; serialize calls (ISR included). Contract: Docs/v0.3_WDG_CONTRACT.md.

### `WWDG_Config`
